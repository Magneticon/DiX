# DiX
Directory and navigation extensions for Windows 2000+

Add into your system path variable for your convenience.

## Suite includes:

**D:**
An advanced directory listing for the command prompt.
<img width="1275" height="707" alt="D" src="https://github.com/user-attachments/assets/0b174927-d0b3-4450-965c-9f1e9ec92263" />

**MARK & RECALL:**
Use mark command (optionally mark label) to store a current %CD% location. Use RECALL (or RECALL label) to return to that location.
<img width="1275" height="707" alt="MARKRECALL" src="https://github.com/user-attachments/assets/ebbc8bf7-0aed-473a-9dab-ac7f7cb0132e" />

**GO & BACK**
Use GO command as CD alternative, allowing you to traverse across drivers seamlessly. Optionally, if you have created a label by MARK command, you can use GO label to get to the marked position. Use BACK command to return to your previous location. 
<img width="1275" height="707" alt="GOBACK" src="https://github.com/user-attachments/assets/43fdea91-e6b0-463f-8a90-03ee526c1b57" />

**ALIASES & UNMARK**
ALIASES command will display all stored labels (they are stored in automatically generated DIX.DAT file in the program directory) while UNMARK will delete label entry in DIX.DAT (created previously by MARK command).
<img width="1275" height="707" alt="ALIASESUNMARK" src="https://github.com/user-attachments/assets/0631a950-7fa8-41f3-8969-bfb260c215dc" />
